Qué conserva y qué debes saber
  • El procesamiento añade un script autónomo y marca los caracteres de la frase elegida; no reemplaza tu página por una plantilla.
  • El analizador HTML del navegador puede normalizar detalles de formato al guardar. No se garantiza identidad byte por byte.
  • Las frases en elementos separados por etiquetas o saltos de línea se comparan con espacios normalizados. Si hay varias coincidencias, debes escoger una.
  • Algunos componentes dinámicos o frameworks que reconstruyen el contenido pueden requerir ajustes manuales.
  • El sonido se genera de forma sintética con Web Audio API y depende de las políticas del navegador y de la interacción del usuario.
